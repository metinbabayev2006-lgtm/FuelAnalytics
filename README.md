# FuelAnalytics

Intelligent Fuel Price Analytics Platform – Hochschulprojekt im Modul
Datenmanagement und Visualisierung, TH OWL, Wintersemester 2026/2027.

## Ziel

Tankstellen nach Ort und Kraftstoffsorte finden, Preise und Entfernungen
vergleichen sowie gespeicherte Preisbeobachtungen analysieren und visualisieren.

## Projektstruktur

- `backend/`: Java 21, Spring Boot und Maven Wrapper (noch einzurichten).
- `frontend/`: React, TypeScript und Vite (noch einzurichten).
- `docs/`: Anforderungen, Architekturentscheidungen und Projektnotizen.
- PostgreSQL und Flyway sind für die persistente Speicherung vorgesehen.

## Aktueller Stand

Die Entwicklungsumgebung wurde geprüft. Die Tankerkönig-Registrierung wartet
auf Freigabe. Die Anwendung ist noch nicht implementiert oder startbar.

## Zugangsdaten und Datenquellen

API-Schlüssel werden später ausschließlich im Backend über Umgebungsvariablen
konfiguriert. Keine Schlüssel, lokalen `.env`-Dateien oder echten Datensätze
in Git veröffentlichen. Beispieldaten müssen als synthetisch gekennzeichnet sein.

Vor öffentlicher Bereitstellung echter Daten sind die Nutzungsbedingungen
und die widersprüchlichen Angaben zur Datenweitergabe zu klären.
